# ESP32 Robotic Arm Control via MQTT & PCA9685

هذا المشروع يحتوي على كود للتحكم في ذراع روبوتية (6 محاور/أذرع) باستخدام شريحة ESP32 ومشغل المحركات PCA9685 عبر بروتوكول MQTT.

## المكتبات المطلوبة (Required Libraries)
* PubSubClient
* Adafruit PWM Servo Driver Library

## التوصيلات (Pinout)
* SDA -> GPIO 21
* SCL -> GPIO 22
